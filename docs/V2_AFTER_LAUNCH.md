# NearMeU V2 After V1 Launch

This file intentionally contains no feature roadmap.

The rule is simple:

- V1 work is limited to the current launch-stability checklist.
- Any product feature, expansion or redesign that is not required to make the current V1 safe and stable for launch is deferred.
- Deferred work will be reviewed and planned fresh as V2 only after V1 has launched.
- Old batch numbers, old future-feature sequencing and old intermediate roadmap labels are not authoritative for current development.

The authoritative pre-launch checklist is [`V1_LAUNCH_CHECKLIST.md`](V1_LAUNCH_CHECKLIST.md).
